## Overview

Sonnox Oxford Compressor is a high-precision compressor trusted in broadcast and mixing, offering extremely transparent dynamics control with comprehensive metering.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Sonnox Oxford Compressor** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Transparent Mode** | Ultra-low distortion VCA compression for transparent gain control |
| **Warmth Mode** | Optional harmonic saturation for musical vintage-style compression |
| **Soft Knee** | Variable soft knee control for smooth onset of compression |
| **Precise Metering** | High-resolution gain reduction and peak/RMS output metering |
